How a request moves

Your agent talks to JEV. JEV picks the model.

JEV routes with a few rules that run in microseconds, with no extra LLM call. When the model speaks the client's protocol, bytes stream through untouched. When it doesn't, JEV translates both ways, including tool calls.

Setup

Two commands, then use your tools as usual.

jev setup finds your clients, backs up their config and points them at JEV. jev uninstall-config restores every file exactly.

  1. Install and add a key

    Any provider works. Gemini and Groq have free tiers.

  2. Start JEV

    jev serve listens on 127.0.0.1:4000.

  3. Run jev setup

    This writes six env entries into ~/.claude/settings.json. Then run claude as normal.

~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:4000",
    "ANTHROPIC_AUTH_TOKEN": "<your JEV key>",
    "ANTHROPIC_MODEL": "jev-auto",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "jev-auto",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "jev-smart",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "jev-fast"
  }
}
  1. Start JEV

    jev serve

  2. Run jev setup

    This adds a marked provider block that uses the Responses wire format. An existing model line is commented out, not deleted.

  3. Run codex

    To try one model directly, run codex -m jev-smart.

~/.codex/config.toml
model = "jev-auto"
model_provider = "jev"

[model_providers.jev]
name = "JEV"
base_url = "http://127.0.0.1:4000/v1"
wire_api = "responses"
  1. Deploy JEV to a public URL

    Cursor sends requests from its own servers, so it can't reach localhost. Deploy free on Cloudflare.

  2. Paste three values

    Go to Settings → Models → API Keys. jev setup copies them to your clipboard.

  3. Choose jev-auto

    Pick it in the Chat or Agent model menu.

Cursor → Settings → Models

Not routed: Cursor Tab and other Cursor-owned features always use Cursor's own models. JEV handles Chat and Agent requests.

  1. Use the JEV URL as the base URL

    The three endpoints are /v1/messages, /v1/responses and /v1/chat/completions.

  2. Use a JEV model name

    jev-auto, or any exact model such as openai/gpt-5.

  3. Read the route

    Every response carries an x-jev-route header, and jev why explains the decision.

MCP toolkit

Turn an API into tools your agent can use.

Start from a template or an OpenAPI spec. Generated servers are one file with no dependencies, and they run free on Cloudflare Workers.

  1. jev mcp import openapi.json

    Each operation becomes a tool. DELETE, admin and internal endpoints are skipped unless you pass --all.

  2. jev mcp test .

    Runs the handshake, checks schemas and calls every read-only tool, all without starting a server.

  3. jev mcp lint .

    Scores names and descriptions, marks tools read-only, write or destructive, and blocks committed secrets.

  4. jev mcp deploy

    Gives you a free public URL on workers.dev.

  5. jev mcp install pets <url>

    Adds the server to every client it finds and prints a one-click Cursor link.

Free cloud

Run it in the cloud for $0.

The same code runs on Cloudflare Workers' free plan, which allows 100,000 requests a day with no cold starts. JEV refuses every request until you set a key, so it never runs as an open proxy.

Deploy
npx wrangler login
jev deploy                                   # prints your JEV key
npx wrangler secret put GEMINI_API_KEY       # once per provider key
jev setup --url https://jev.<you>.workers.dev --key <your JEV key>
