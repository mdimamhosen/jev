# jev-guide

Tools for setting up [JEV](https://github.com/mdimamhosen/jev) and installing MCP servers into Claude Code, Codex and Cursor. A zero-dependency [MCP](https://modelcontextprotocol.io) server (Streamable HTTP), generated by [JEV](https://github.com/mdimamhosen/jev).

## Install

**Claude Code**
```sh
claude mcp add --transport http --scope user jev-guide https://jev-guide.jevrouter.workers.dev/mcp
```

**Codex**
```sh
codex mcp add jev-guide --url https://jev-guide.jevrouter.workers.dev/mcp
```

**Cursor** — add to `~/.cursor/mcp.json`:
```json
{ "mcpServers": { "jev-guide": { "url": "https://jev-guide.jevrouter.workers.dev/mcp" } } }
```

**All at once:** `jev mcp install jev-guide https://jev-guide.jevrouter.workers.dev/mcp`

## Develop

```sh
jev mcp dev        # http://localhost:7337/mcp, reloads on change
jev mcp test .     # protocol + tool checks, no server needed
jev mcp lint .     # tool quality + safety score
```

Visual inspector: `npx @modelcontextprotocol/inspector` → connect to `http://localhost:7337/mcp`.

## Deploy (free, Cloudflare Workers)

```sh
npx wrangler login
npx wrangler deploy
npx wrangler secret put MCP_TOKEN   # optional: require "Authorization: Bearer <token>"
```

Live at `https://jev-guide.jevrouter.workers.dev/mcp`.

## Publish to the official MCP Registry

```sh
jev mcp publish    # validates server.json and prints the exact steps
```

## Security

- Tools marked `destructiveHint` should be confirmed by the user before running.
- Keep secrets in Worker secrets / env vars — never in `server.js`.
